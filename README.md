# Festa do Davi — GitHub Pages

Esta pasta é a versão estática do convite. Publique **o conteúdo desta pasta** na raiz do repositório do GitHub Pages (ou na pasta configurada como origem no GitHub). O arquivo de entrada é \`index.html\`; os arquivos de \`images/\` e \`fonts/\` devem permanecer juntos.

O formulário envia as confirmações para \`https://festa-do-davi-2026.gaite.chatgpt.site/api/rsvp\`. As respostas ficam salvas no banco D1 do Site atual, na tabela \`rsvps\`. O GitHub Pages hospeda apenas a página; a API e o banco continuam no Site atual.

O Site atual precisa permitir acesso público para que visitantes do GitHub Pages consigam enviar a confirmação. **No momento, esse acesso público ainda não foi liberado.** A página não pede WhatsApp. O primeiro adulto usa o campo “Seu nome”; ao aumentar a quantidade de adultos ou crianças, surgem campos para os demais nomes. Depois de um envio bem-sucedido, abre a tela de tamanhos (roupas: 2 anos; calçados: 19), com a tabela expansível. A localização abre pelo bloco no topo. A tabela de tamanhos também pode ser aberta pelo botão na parte inferior. No celular, os personagens ficam lado a lado.

Para publicar: crie um repositório, copie os arquivos desta pasta e, em **Settings → Pages**, escolha a branch e a pasta onde colocou o \`index.html\`. Não publique o código do projeto \`davi-site\` como se fosse uma página estática.
